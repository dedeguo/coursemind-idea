# 课程任务：IDEA 工具窗口原型

日期：2026-10-24。入口：[UI.html](UI.html)。基础卡片和关联交互已落地为 0.3.1；本次新增的 Markdown 排版、聊天气泡和默认账号首页先修改原型，尚未加入原生插件安装包。

## 布局

登录后默认进入账号与使用概览，再通过“课程任务”入口进入学习页面。工具栏保留 CourseMind 标识、刷新图标和设置入口。模块标题和入口统一为“课程任务”，内部使用“任务列表 / 我的对话”同级页签，避免标题和页签重复。学习页的账号压缩为一行。工具窗口内只滚动内容区，采集状态固定在底部；详情替换当前列表，使用“返回任务列表”按钮恢复列表，避免长列表和详情上下堆叠。

任务卡片展示课程、标题、简短要求、教学班、类型及截止时间；状态使用小标签，弱化辅助文字。关闭任务保留阅读入口，隐藏关联和任务提示操作。详情仅突出一个主要动作“关联已有 AI 对话”，窗口任务提示和网页查看作为次要动作。

对话卡片使用第一条学生消息作为标题，展示来源、时间、消息数、正文预览和已有任务标签。未关联状态明确显示。课程、正文搜索与关联状态筛选位于列表上方；进入批量选择后才显示复选框和底部关联操作条。

关联面板从底部打开，在原有侧栏宽度内选择目标任务与添加/解除操作；先预览实际变更数量，再明确确认。确认后演示卡片标签更新；关闭或取消不修改关联。任务提示独立显示，明确“仅当前窗口，不会自动关联”。

## 原型范围与验证

任务说明与对话正文新增 Markdown 排版示例：分级标题、粗体、列表、行内代码、带语言标识及复制按钮的代码块、引用和表格。原型使用预置的虚构内容演示渲染效果，不引入在线脚本或新增 Markdown 解析依赖；原生插件的解析实现另行落地。

对话详情采用与网页端一致的方向：AI 气泡靠左、用户气泡靠右，头像标识与气泡对应；每条消息显示发送者及北京时间，包含日期、时分秒。AI 使用主题背景，用户使用浅绿色背景，深色主题同步适配。消息宽度随侧栏缩放；长代码与宽表格在各自区域内滚动，不撑宽侧栏。保留既有任务关联和网页查看入口。

本轮浏览器走查确认：初始首页与模拟登录后均为账号页；任务示例包含 4 个分级小节、2 个代码块和 3 行验证场景；对话示例 4 条消息均有时间，用户为反向行、AI 为正向行。320 px 深色预览无整页横向溢出，代码区独立横滚；复制按钮返回“已复制”，浏览器没有 JavaScript 错误。全部使用预置示例，没有读取截图中的真实对话作为演示数据。

提供 320 / 390 / 520 px 侧栏宽度和浅色/深色切换。保留账号概览、登录和插件设置原型，并在账号概览增加课程入口。全部使用虚构数据，没有服务端请求、持久化写入或真实账号操作；刷新页面恢复演示数据。网页查看按钮只说明真实插件的跳转行为。

已在浏览器走查任务列表/详情、关闭任务、任务提示、对话预览、搜索空状态与清除筛选、添加与解除关联的两步确认、原有账号页面往返；320 与 520 px 无侧向溢出，检查深色界面，未出现 JavaScript 错误。

原生实现使用现有 Swing/IntelliJ 组件与主题颜色：列表采用自定义卡片渲染，详情使用同一区域切换；关联使用侧栏内独立视图，底部固定“预览变更 / 确认”操作，不增加系统确认弹窗。沿用现有控制器与权限校验，不引入 WebView 或新的业务状态。

任务搜索按回车或搜索按钮执行；对话正文检索、关联状态和教学班筛选由服务端完成。对话预览显示前 20 条消息，完整正文可跳转教学工作台。旧服务端缺少标题或任务标签时显示空状态，不再把采集端 session ID 用作标题。采集状态取自既有只读诊断，列表刷新仅显示“刚刚同步”，不作为采集成功的证据。
