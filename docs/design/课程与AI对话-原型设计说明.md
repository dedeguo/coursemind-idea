# 课程任务：IDEA 工具窗口原型

日期：2026-10-24。入口：[UI.html](UI.html)。本次修改原型，不修改运行中的 Swing 插件。

## 布局

工具栏保留 CourseMind 标识、刷新图标和设置入口。模块标题和入口统一为“课程任务”，内部使用“任务列表 / 我的对话”同级页签，避免标题和页签重复。账号压缩为一行。工具窗口内只滚动内容区，采集状态固定在底部；详情替换当前列表，使用“返回任务列表”按钮恢复列表，避免长列表和详情上下堆叠。

任务卡片展示课程、标题、简短要求、教学班、类型及截止时间；状态使用小标签，弱化辅助文字。关闭任务保留阅读入口，隐藏关联和任务提示操作。详情仅突出一个主要动作“关联已有 AI 对话”，窗口任务提示和网页查看作为次要动作。

对话卡片使用第一条学生消息作为标题，展示来源、时间、消息数、正文预览和已有任务标签。未关联状态明确显示。课程、正文搜索与关联状态筛选位于列表上方；进入批量选择后才显示复选框和底部关联操作条。

关联面板从底部打开，在原有侧栏宽度内选择目标任务与添加/解除操作；先预览实际变更数量，再明确确认。确认后演示卡片标签更新；关闭或取消不修改关联。任务提示独立显示，明确“仅当前窗口，不会自动关联”。

## 原型范围与验证

提供 320 / 390 / 520 px 侧栏宽度和浅色/深色切换。保留账号概览、登录和插件设置原型，并在账号概览增加课程入口。全部使用虚构数据，没有服务端请求、持久化写入或真实账号操作；刷新页面恢复演示数据。网页查看按钮只说明真实插件的跳转行为。

已在浏览器走查任务列表/详情、关闭任务、任务提示、对话预览、搜索空状态与清除筛选、添加与解除关联的两步确认、原有账号页面往返；320 与 520 px 无侧向溢出，检查深色界面，未出现 JavaScript 错误。

后续落地继续使用现有 Swing/IntelliJ 组件与主题颜色：为列表增加自定义单元格渲染，详情使用同一区域切换，关联沿用现有控制器与权限校验。不需要为此引入 WebView 或新的业务状态。
