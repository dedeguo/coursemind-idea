## 已实现

| 能力 | 实际行为 |
| --- | --- |
| 双网络配置 | 公网/校园内网选择，两套地址可编辑保存；内置公网 `http://8.140.216.36:29236`、校园 `http://10.50.79.225:8000`，首次默认公网 |
| 实例与入口分离 | 沿用采集端协议：公网地址作为 `server_id`，当前入口为 `server_url`；同实例入口切换不重写队列或轮换账号 |
| 配置迁移 | v1 单地址原样规范化保留到公网字段，并提示原用途未明确；已有用户配置优先，不被默认值覆盖。首次无显式配置时采用有效共享服务器/实例配置，损坏共享配置报错 |
| 连接设置 | 按原型组织单选及双地址，显示生效网络/地址、HTTP 状态、凭证存在状态；编辑预览、测试连接及应用/确定/取消继续区分 |
| 切换校验 | 已登录且同实例切换入口时，用目标 `/student/me` 校验同一 student_id；失败保留配置。实例变更先提示清除共享登录；共享入口冲突另行提示，不静默覆盖 |
| 修改密码 | 身份卡片内展开当前/新/确认密码表单；8～128 位策略沿用服务端，校验一致性，提交防重复；取消、提交及身份变化清空输入 |
| 共享 token | 调用已有 change-password 接口，成功后 DPAPI 写入新 token 并轮换 sessionId；持有旧 sessionId 的窗口不能删除或覆盖新会话 |
| 身份刷新 | 启动及应用恢复焦点重读共享状态并用 `/me` 校验；插件内身份事件更新各窗口；刷新合并，关闭项目/面板后不回填 |
| 失效处理 | 撤销/过期不继续使用旧身份，清除匹配旧状态的上传凭据；外部退出不从本地缓存复活共享登录 |
| 共享文件 | 状态写入使用共享目录锁；登录/退出/换服失败尽力回滚 auth.dat、identity.json、config.json，不另建凭据来源 |

## 采集端配套改动

同步修改 `coursemind-collect/extension` 的认证与客户端配置写入，新增 `sharedStateLock.ts`，与 IDEA 共用 `%LOCALAPPDATA%\CourseMind\state-write.lock` 的目录租约协议。

协议通过原子创建目录排他、最多等待 15 秒、操作完成后释放；崩溃残留不自动抢锁。确认所有 IDE 已关闭后方可人工检查残留锁。Node 的嵌套操作可复用有效租约，已释放租约不能被延后的异步回调再次复用。修改密码输入期间不占写锁。

采集端同时增加旧会话写入保护及登录在途配置/共享凭据校验。旧版已安装扩展不认识该协议，因此完整的多写入方保护需要两端均安装本次配套版本；仅更新 IDEA 不能宣称解决旧扩展的全部并发竞态。

本次不修改 collector 二进制，不重新实现其解析、队列和上传。插件不改写旧队列身份/服务器，历史无 server_id 的队列按既有 collector 兼容行为处理；真实 collector 并发、断网及队列回放仍需 R5 联合验收。
