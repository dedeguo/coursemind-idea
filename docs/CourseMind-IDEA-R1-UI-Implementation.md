## 已实施

- 工具窗口采用品牌/设置头部、纵向登录卡片、身份卡片及统一间距；缺少服务器配置仍显示登录区及连接设置入口，不引入向导。
- 登录区提供用户名/密码、全宽登录按钮、分配账号说明、生效地址、修改连接入口及忘记密码说明；回车可进入密码框或提交。
- 身份卡片展示头像首字、姓名、学号、班级、账号状态及退出；移除首页的服务器/有效期堆叠和连接检测按钮，连接检测集中到设置页。
- 设置页按客户端配置、AI 编程工具、采集客户端组织；共享配置路径和同步选项折叠在详情区；沿用 IDEA 自带应用/确定/取消。
- 将原 CollectorHookPanel 拆为 Hook 和 collector 两块视图，复用既有检查、预览应用、移除、部署、自检服务及确认流程。
- 长地址、路径和错误使用纯文本换行，避免当作 HTML；视图跟随可用宽度并可纵向滚动，输入框保持正常高度；主题颜色和间距采用平台组件。
- 连接测试监听器只注册一次，设置重开后旧异步结果不回填新视图；项目关闭后不再更新工具窗口。
- 新增实际视图的布局回归及本地离屏预览；测试使用专用身份/路径数据，不登录、不部署、不写入真实共享凭据或 Hook。

## 验证结果

执行 release（IC 2023.3 / Java 17）基线的 `gradlew.bat test buildPlugin --console=plain`，共 52 个测试通过，失败/错误为 0。包括原有认证、配置、API 错误映射、collector 和 Hook 回归，以及新增的 4 个 UI 布局用例。

布局用例覆盖 320 像素窄窗口、长服务器地址、600 像素宽窗口、身份/错误视图、暗色短窗口滚动，以及设置区与详情展开；检查输入框高度、控件横向边界及测试未创建采集运行目录。

离屏预览由真实 Swing 视图在 IDEA 测试平台中渲染，位于 `build/reports/r1-ui/`，含 login-narrow、login-wide、identity-narrow、error-narrow、login-dark-short、settings、settings-details。预览中的身份及检测内容仅为测试夹具，不是正式界面默认值；离屏图不等同于实际 IDE 截图。

安装包：`build/distributions/coursemind-idea-0.3.0.zip`。本次不修改插件版本号，不发布 Marketplace。`-local.zip` 为原有本地产物，本次未更新，不作为 R1 交付证据。
