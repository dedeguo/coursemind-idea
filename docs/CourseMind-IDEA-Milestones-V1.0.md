## 1. 计划原则与现状

2026-10-21 发布基线调整：优先开发与验收环境为教室 Windows / IDEA Ultimate 2025.1.3；release 默认 IU 2025.1.3 / JDK 21 / since-build 251，输出仍为 Java 17 字节码。继续推进 R3/R4 前，先在该平台编译、测试并启动调试，核对现有核心流程。已有旧基线测试结果不得视为新平台验收通过。

本计划从已有功能继续开发，不重新实施已接入的登录、CodeBuddy Hook、collector 部署和服务器配置。历史 M0/M1/M2 保留原含义；本文新增 R0～R5 里程碑，替代需求文档旧 S0～S4 的后续执行顺序，R 编号不代表插件版本号。

状态依据为用户反馈与 2026-10-21 当前源码静态核对，未在本次规划中运行插件或完成端到端验收。“已有实现”不等于满足新版需求的全部验收项。

| 能力 | 当前判断 | 依据及剩余工作 |
| --- | --- | --- |
| 登录、身份及退出 | 已有实现，继续复用 | AuthService、ApiClient、CourseMindPanel；仍需按原型改造展示并验证共享状态和失效处理 |
| 共享凭据 | 已有实现，待并发验收 | SharedAuthStore、SharedIdentityStore、SharedConfigStore、Dpapi；跨进程一致性和换号队列安全需验证 |
| 服务器地址及连接测试 | 已有单地址实现 | CourseMindSettings、CourseMindConfigurable；双地址默认值、网络选择和配置迁移待补齐 |
| CodeBuddy Hook | 已有实现 | CodeBuddyHooks、CollectorHookPanel；检查、预览应用、移除可复用，批量工具 UI 待整合 |
| collector 部署 | 已有实现 | CollectorService、BundledCollector；版本仲裁、备份、自检逻辑可复用，统一检测/修复及状态待完善 |
| 工具窗口和设置页 | 已有功能界面，需按原型重整 | 当前 FormBuilder 等布局未按 HTML 的卡片、分区和信息层级组织 |
| 修改密码 | 当前访问层未接入 | 待新增接口调用、表单和共享 token 更新 |
| 今日 AI 使用及会话预览 | 当前访问层/窗口未接入 | 待新增统计模型、请求、刷新状态与真实会话元信息预览 |
| Trae、Claude Code、WorkBuddy 配置 | 当前 IDEA 侧未见适配实现 | 依据采集端现有适配器补齐，不重写采集解析器 |

源码主要位于 `src/main/java/top/chende/coursemind/`。实际开发开始前重新核对相关文件及在途改动；不因本表将已有能力判定为已通过完整验收。

## 2. UI 作为后续开发的验收基线

后续所有用户可见开发必须遵循 HTML 的页面划分、信息层级、分区顺序、交互和文案。使用 IDEA 原生组件实现，不要求直接嵌入 HTML，也不硬编码网页字体或颜色；保持 IDE 主题、缩放和键盘操作能力。新增功能必须放入对应设计区域，不能继续随功能追加而堆叠控件。

| 页面/区域 | 必须遵循的组织方式 |
| --- | --- |
| 未登录窗口 | 品牌及设置入口 → 欢迎说明 → 用户名/密码/登录 → 当前网络及地址/修改连接 → 忘记密码说明 |
| 已登录窗口 | 品牌及设置入口 → 身份卡片（姓名、账号、班级、状态、修改密码/退出）→ 可展开改密区 → 可折叠今日 AI 使用卡片 |
| 今日 AI 使用 | 日期 → 四项指标的两列布局 → 主要主题 → 最近会话 → 内联会话预览 → 采集状态与最近同步 |
| 设置页 | 客户端配置 → AI 编程工具 → 采集客户端；使用 IDE 的应用/确定/取消行为 |
| 客户端配置 | 公网/校园单选、两套可编辑地址、生效地址、凭证状态及连接测试 |
| 工具与采集客户端 | 四工具勾选及逐项状态、带数量的配置按钮；采集开关、路径、环境检测及修复 |

UI 验收必须在实际 IDEA 中留存截图或演示记录，对照原型检查亮/暗主题、窄工具窗口、长地址/标题、滚动、缩放及状态提示。界面不要求像素级照搬浏览器尺寸，但不得出现控件重叠、输入框过度拉伸、内容截断后无法查看、主次操作混杂或错误信息无位置可读的问题。

原型中的示例姓名、数字、对话正文和“演示成功”不进入生产界面。R1 尚未接入的区域可暂不展示，不能用示例数字、假正常状态或可点击的无效按钮充数。后续 R2～R4 接入时继续按同一原型验收，不把 UI 一致性推迟到发布阶段。

## 4. 各里程碑工作与退出条件

### R0：确认已开发基础

- 核对已有入口和服务边界，记录源码、插件/collector 版本、共享文件及构建剖面，列出新版需求差异。
- 使用真实测试环境复查登录/身份/退出、连接测试、collector 部署与重复部署、CodeBuddy Hook 预览应用及第三方条目保留。
- 确认 IDEA 独立写入 Hook 后可采集真实提问及回答；若暂无账号或环境，明确记录“已有实现、端到端待验证”，继续不依赖该结果的 UI 工作，但 R5 前必须补齐。

退出条件：已有实现与待补项边界清楚，有可复用的回归步骤及构建基线；不重做历史 M0～M2。交付现状清单和回归记录。

### R1：按 UI 设计重整界面

- 拆分窗口的视图、状态和操作绑定，保留并复用 AuthService、collector 和 Hook 服务；避免将业务逻辑再次复制到界面。
- 实现原型的未登录布局、身份卡片、设置入口及错误/加载展示。首页不直接堆放凭据有效期、共享配置路径或部署诊断等维护信息，详细信息放设置/诊断区域。
- 设置页重整为三个设计分区，将既有服务器、连接测试、collector 和 CodeBuddy 操作迁入对应区域；保留已有预览/移除等必要维护能力，可放二级操作。
- 预留今日摘要、改密和多工具的数据接入位置；阶段尚未接入的区域不提供假数据或假成功。
- 验证新 UI 中已有登录/退出、地址保存、部署、Hook 操作可用，提交实际 IDEA 的前后截图及亮/暗主题、窄窗口检查记录。

退出条件：现有功能按原型组织，主流程无回归，满足第 2 节 UI 规则。相关验收：CUR-02、04、06、08 的已有功能部分；该阶段不宣称全部通过。

### R2：补齐身份与公网/校园配置

- 扩展配置模型为公网地址、校园地址和当前网络；内置 `http://8.140.216.36:29236`、`http://10.50.79.225:8000`，首次默认公网。
- 定义旧单地址配置及共享配置迁移：保留已有用户/机房地址，不用默认值覆盖；不能判断旧地址用途时明确保留和提示，不静默猜测。重启保留，升级不覆盖。
- 按原型完成双地址编辑、生效地址、上传凭证状态和应用/确定/取消；连接测试结果与登录状态分开显示。
- 接入修改密码、输入校验、取消清空、token 更新；完善登录过期、窗口恢复焦点及跨 IDE 身份同步。
- 明确两网络地址是否指向同一服务实例，沿用共享协议的 serverId 规则；不能只因 URL 不同就静默换身份，也不能无依据将两台不同服务器认作同一实例。变更身份/实例时按需求处理凭据和旧队列。

退出条件：CUR-02～04 完整通过，CUR-11 的身份/配置部分通过；无默认值覆盖和串身份，所有操作按原型落位。交付配置迁移说明与接口验证记录。

### R3：今日摘要、会话与状态

- 接入 `/api/v1/student/me/stats` 和真实类型，展示日期、四项指标、主题及最近会话，提供折叠和内联预览。
- 最近会话先保证真实元信息；无正文接口时明确“暂不提供对话正文”，不编造接口或展示原型正文。
- 实现登录后、焦点恢复及手动刷新；去重并处理加载、空、失败、过期，阻止旧身份/服务器的在途响应回填。
- 读取实际 collector 状态，区分配置、事件、队列和上传确认；证据不足标记未知，最近同步不使用统计刷新时间替代。
- 对照工作台/服务端同一账号、日期及时间范围验证数据，换号/换服立即清空个人缓存。

退出条件：CUR-09、10 及 CUR-11 的摘要部分通过，CUR-13 的状态真实性通过；首页结构与原型一致，失败不显示为零或采集正常。交付数据对照与异常演示记录。

### R4：四工具与采集管理完善

- 复用已完成 CodeBuddy 适配，按采集端实现补齐 Trae、Claude Code、WorkBuddy；核对各自路径、事件、执行环境和支持版本。
- 接入四项独立勾选、默认选择、数量按钮、逐项检测和批量结果；未勾选项不修改，未安装/不支持时明确跳过及原因，部分失败可重试。
- 统一配置预览、备份、幂等合并、并发冲突处理和受管条目恢复；不破坏第三方 Hook，不中断 Trae 现有采集。
- 接通真实共享采集开关，完善路径、环境检测与修复结果；验证较新 collector 不降级、失败恢复及队列不丢失。
- 测试连接/环境检测为即时只读；Hook 配置及修复为明确范围的即时操作，不因设置页取消被误称已回滚。

退出条件：CUR-05～08 通过，四种工具在声明支持环境各有真实采集记录和版本范围；其他工具缺少验证环境时标为待验证，不直接计为已完成。相关界面继续满足原型。交付适配矩阵与共享配置回归记录。

### R5：交付验收

- 汇总 CUR-01～14 全部结果；覆盖多窗口、多 IDE、换号/换服、断网恢复、重复触发、失效凭据、隐私及诊断。
- 机房预配置及还原后验证：无向导、无镜像旧凭据，学生登录可用，明确本地队列的还原限制。
- 同一 release ZIP 优先完成 IU 2025.1.3 的 Plugin Verifier 检查与教室真实环境核心流程验收，覆盖主题/缩放、身份、双网络、collector、Hook、真实采集、中文路径、普通权限和重启；IU 2026.2 为补充兼容检查与冒烟目标。保存未验证项及原因，local 包不作为教室兼容证据。
- 交付安装包、变更说明、机房部署/使用/排障文档、兼容报告和已知限制；不自动发布 Marketplace。

退出条件：本期所有 P0 具有可核查通过证据；未验证项明确且不宣称已支持。未达验收时保留待完成状态，不以“代码已写完”结束里程碑。
